# lejepa

LeJEPA — *Lean Joint-Embedding Predictive Architecture*. This package provides the statistical primitives (Sketched Isotropic Gaussian Regularization / SIGReg, plus univariate and multivariate normality tests) consumed by the GeoDRO-LeJEPA training framework.
